# Via Breakfast AI

## 本機工具

直接用瀏覽器開啟 `index.html`，即可使用 Via 早餐智能顧問。第一版不需要安裝套件或啟動伺服器；資料會安全地保存在目前瀏覽器的 Local Storage，可透過頁面右上角匯出為 JSON 備份，或在另一台裝置匯入。

使用順序：先在「個人設定」設定健康目標，再於「食材庫存」新增食材，最後到「早餐推薦」產生建議。早餐後用「早餐回饋」確認實際吃掉的份量，系統才會更新庫存、紀錄與食材接受率。

## 資料與安全

本工具不會呼叫外部 API 或上傳照片；早餐資料僅保存在目前瀏覽器。請勿在共用裝置輸入敏感健康資料，並可使用「清除本機資料」移除本機紀錄。完整安全說明見 `SECURITY.md`。

Via 早餐智能顧問是一個以庫存、營養規則、健康目標與使用者回饋為基礎的個人化早餐決策系統。

## 專案結構

- `Agent.md`：AI Agent 核心規格與決策規則。
- `database/`：食材庫存、早餐紀錄、偏好、規則與身體回饋資料。
- `prompts/`：早餐規劃、營養檢查、庫存更新與回饋分析提示詞。
- `knowledge/`：營養、食安與食材資料參考。
- `images/breakfast_photos/`：使用者早餐照片。

## 開始使用

1. 在 `database/food_inventory.json` 登錄現有食材。
2. 在 `database/user_preferences.json` 設定健康目標及飲食偏好。
3. 依 `Agent.md` 與 `prompts/breakfast_planner.md` 產生早餐建議。
4. 早餐後新增回饋與實際攝取紀錄，更新庫存與偏好資料。

> 營養數值僅供一般飲食規劃參考；如有疾病、過敏、孕期或特殊醫囑，應優先依循醫療專業人員建議。
